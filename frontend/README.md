# Andre van Heerden — Portfolio

Portfolio site for my UX case studies, websites and apps. Currently a "coming soon" page.

Built with React + Vite. Hosted on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Then open the link it prints (usually http://localhost:5173).

## Build

```bash
npm run build
```

Vercel detects Vite automatically (build command `npm run build`, output folder `dist`).
